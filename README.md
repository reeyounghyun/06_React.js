# 06-React.js

React 학습 기록 저장소입니다. 일차별 프로젝트는 각 폴더에서 독립적으로 실행할 수 있습니다.

| 폴더 | 내용 |
| --- | --- |
| [01-react-basic](./01-react-basic) | React 기초 — React 시작하기, JSX와 컴포넌트, Props와 State, 동적인 UI 구현 + 실습 프로젝트 |
| [02-react-day2](./02-react-day2) | 불변성과 State 관리, 폼 다루기, 컴포넌트 간 데이터 흐름, Hooks(useRef·useEffect·useReducer·커스텀 훅) + Todo 프로젝트 |
| [03-react-day3](./03-react-day3) | 전역 상태 관리(Context API·Zustand), HTTP 통신(axios·TanStack Query) |

## 실행 방법

```bash
cd 01-react-basic
```
